# Entrega pelo GitHub

Repositório da atividade: [Renovato86/confeitaria_Sistemas_Distribu-dos](https://github.com/Renovato86/confeitaria_Sistemas_Distribu-dos).

O repositório reúne código-fonte, configuração do Redis, instruções de execução, relatório e evidências. Para baixar tudo, use **Code > Download ZIP**, extraia o arquivo e abra o `README.md` na pasta principal.

O relatório está disponível como [texto para leitura](relatorio.md) e como [documento editável](Relatorio_Confeitaria_Redis_Streams.docx). Preencha os nomes dos integrantes antes da entrega. Quando a atividade pedir um link, utilize o endereço deste repositório.

Para manter uma cópia local com Git:

```bash
git clone https://github.com/Renovato86/confeitaria_Sistemas_Distribu-dos.git
cd confeitaria_Sistemas_Distribu-dos
```

Leia `docs/roteiro-apresentacao.md` para preparar a demonstração em sala. A pasta `evidencias/` contém os registros originais dos testes.

As evidências incluídas foram produzidas numa execução de referência em Linux. O [README](../README.md) explica a instalação e a execução; o [guia técnico](guia-tecnico.md) detalha os experimentos. Se substituir as evidências pelas suas, atualize também versões, números, horários e identificadores descritos no relatório.
